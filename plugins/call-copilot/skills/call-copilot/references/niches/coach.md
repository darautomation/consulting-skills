# Preset: coach (life, career, business, health)

- **Call types**: chemistry call, kickoff, regular session, milestone review.
- **Discovery questions**: Where are you now vs where you want to be in 6 months? What has stopped you so far? What are you willing to change weekly? How will we both know it works?
- **Core block**: goal → obstacles → one commitment for the week.
- **Client recap**: insight of the session in the client's words, the commitment, accountability check date.
- **Outcome metrics**: commitments kept per week, milestone dates, client-chosen KPI (income, weight, applications sent).
- **Objections**: "I can do it alone" → ask what stopped them last time; "not now" → find the date they will start.
