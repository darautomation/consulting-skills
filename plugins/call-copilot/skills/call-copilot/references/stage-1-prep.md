# Stage 1. Pre-call brief

Goal: in 60 seconds of reading, the consultant knows who is coming, what happened before, what this call must achieve and what to ask.

## Gather (in this order, stop when you have enough)

1. **Calendar event**: title, time, duration, attendees, description, booking-form answers, meeting link. Duration sets the size of the call plan.
2. **Previous recaps / CRM notes** for this person (files, Notion, Google Docs, whatever the user has connected).
3. **Messenger history** (Telegram, WhatsApp, email thread): last 30-50 messages. Look for: what they asked, what was promised, open questions, tone, voice notes (transcribe them, never write "listen before the call").
4. **Email**: search every spelling of the name, every address, attachments.
5. **Public profiles** (only if web search is available): LinkedIn, Instagram, company site, Telegram channel. Max ~6 searches per person. Apply the two-signal rule. Cache what you found if the user keeps a contacts file.

If a source is not connected, skip it silently and list it under "Not checked" at the end. Do not stall.

## Brief format

```
⚡ Call HH:MM (duration), {First name} {@handle or email}

WHO: 2-3 sentences. Role, situation, how they found us. Only verified facts.
LINKS: only profiles that passed the two-signal check.
HISTORY: dated bullets with short quotes ("12.03: asked about X", "15.03: we sent Y, no reply").
GOAL OF THIS CALL: one sentence + the measurable outcome (booked next session, signed, paid deposit, decision on X). Money figure if the niche has one.
PLAN (fit to duration):
  0-5 min  rapport, confirm agenda
  5-20     discovery (questions below)
  20-35    {niche-specific core}
  35-45    next step, close
QUESTIONS (5): open questions that qualify and deepen. From the niche preset, adapted to this person.
OBJECTIONS (3-4): likely objection → one-line answer.
NEXT STEP: option A (ideal) / option B (fallback).
ASK ME: facts I could not find that you should confirm on the call.
NOT CHECKED: sources that were unavailable.
```

## Rules

- Main point in the first two lines. No intro, no outro.
- If the guest is a peer (another consultant bringing their client, a partner), the call is discovery and partnership, not a sale: say so in GOAL.
- Never contact the client, never create or move calendar events from this stage.
- Thin data is fine. Fabricated data is not. Put gaps into ASK ME.
- Write in the consultant's working language (config `language`), quotes stay in the original language.
