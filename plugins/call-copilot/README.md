# call-copilot

Client-call workflow for consultants and helping professions: **Prep → Capture → Recap → Follow-up → Results**.

- Pre-call brief from calendar, chat history, email and public profiles
- Transcription: Zoom cloud recordings, audio files (Whisper API or local), VTT/SRT
- Client recap from platform notes + internal CRM note
- Follow-up draft with pre-send guard (right person, no placeholders, no AI tells)
- Progress report and next-session agenda
- Niche presets: coach, psychologist/therapist, realtor, lawyer/accountant, financial advisor, consultant

Install: `/plugin marketplace add darautomation/consulting-skills` then `/plugin install call-copilot@darautomation`.

Start with `skills/call-copilot/SKILL.md`. Optional config: `skills/call-copilot/templates/config.example.md`. Full example: [examples/coach-session](../../examples/coach-session).
