# advisor-copilot

Workflow for financial advisors, planners and wealth managers who run long-term client service.

- Discovery brief with money snapshot, goals and residency
- Meeting recap with confirmed money facts and compliance notes
- Financial plan draft: goals, balance sheet, cashflow, three buckets (protection / income / growth), asset location, scenarios
- 13-meeting service year with one outcome per meeting
- Annual review template

Install: `/plugin marketplace add darautomation/consulting-skills` then `/plugin install advisor-copilot@darautomation`. Pairs with `call-copilot` for transcription and pre-send checks.
