# Скиллы для консультантов в Claude

**Конспекты созвонов больше не пишутся руками.** Два открытых скилла для Claude берут на себя всё вокруг встречи с клиентом: бриф до звонка, расшифровку, итог для клиента, письмо после встречи и отчёт о прогрессе перед следующей сессией.

Для тех, кто работает через Zoom: коучи, психологи, риэлторы, юристы, бухгалтеры, финансовые советники, консультанты, агентства.

[English](README.md) · [Пример результата](examples/coach-session) · [Pro и внедрение](#pro-и-внедрение-под-ключ)

```
Бриф  →  Запись  →  Итог  →  Отправка  →  Результат
за час   Zoom,      клиенту   после       прогресс и
до       аудио,     + заметка вашего      повестка
звонка   VTT        в CRM     «да»        следующей встречи
```

## Что внутри

**call-copilot** для любой консультационной и помогающей профессии. Бриф по календарю, переписке, почте и открытым профилям. Расшифровка Zoom, аудио или VTT. Итог для клиента и отдельная заметка в CRM. Черновик сообщения с проверкой перед отправкой. Отчёт о прогрессе и повестка. Готовые настройки под 6 ниш: коуч, психолог, риэлтор, юрист и бухгалтер, финсоветник, консультант.

**advisor-copilot** для финансовых советников. Бриф к первой встрече, итог встречи с цифрами клиента, черновик личного финплана (цели, поток, три корзины, где держать активы), год сопровождения из 13 встреч, годовой разбор.

## Почему ему можно доверять клиентов

Скилл вырос из конвейера, который каждый рабочий день обслуживает встречи нашей консалтинговой практики. Правила в нём появились после реальных ошибок.

Однажды итог встречи ушёл не тому клиенту. С тех пор каждое сообщение проходит проверку: имя получателя есть в заметках, чужих имён нет. `guard_check.py` понимает падежи («Ольгу», «Марком») и латиницу.

Клиенту уходят заметки Zoom почти дословно, а не пересказ ИИ. Клиент видел, как их писали на встрече, и с ними согласен. Свежий пересказ добавляет новые формулировки, иногда новые факты.

Без вашего «да» не уходит ничего. Скилл готовит черновик, отправляете вы.

Факты не выдумываются. Пробел превращается в вопрос «уточнить на звонке». Профиль в соцсети засчитывается, только если совпали два признака.

Whisper на тишине сочиняет «Продолжение следует» и «Субтитры сделал...». Тихие куски пропускаются, такие строки вычищаются.

## Установка

**Claude Code:**
```
/plugin marketplace add darautomation/consulting-skills
/plugin install call-copilot@darautomation
/plugin install advisor-copilot@darautomation
```
Дальше обычными словами: «подготовь бриф к звонку в 15:00», «расшифруй call.m4a и напиши итог для Анны», «прогресс Даниила перед 4-й сессией».

**Claude.ai и Claude Desktop:** скачайте zip из [Releases](../../releases), загрузите в Настройки → Возможности → Навыки.

**Другие агенты:** формат открытый ([Agent Skills](https://agentskills.io)), папку `plugins/*/skills/*` можно положить в любой агент, который его читает.
